**Update `nook` on every machine before you mark any bucket or secret as Ask first.** Earlier versions cannot ask for approval. For a covered secret they stop with "… needs the owner's approval, and this nook version cannot ask. Update nook." and get no value. Secrets without a mark keep working on every version.

With this version, when `nook run` needs a secret covered by an Ask first mark, it prints the approval link and waits up to 10 minutes for the owner's decision. It exits 77 when the owner denies and 75 when the request expires. Until the web app ships its Ask first screens, marks can only be set through the owner API, and the approval link opens a page the web app does not serve yet.
