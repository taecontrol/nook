**`nook run` now masks injected values in output that is not a terminal.** When stdout or stderr goes to a pipe or a file, each exact occurrence of an injected value of 8 or more characters becomes `<nook:bucket/NAME>`, for example `<nook:work/acme/GH_TOKEN>`. Output to a terminal is unchanged. Pass `--no-masking` to get the raw output for one command.

Masking is best effort, not a security boundary. Values shorter than 8 characters are not masked, and neither are transformed forms such as base64 or URL-encoded values.
