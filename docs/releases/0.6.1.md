**Cancelling `nook run` while it asks for values now withdraws the request.** Before, a Ctrl+C or SIGTERM sent before the first answer arrived ended `nook run` without withdrawing the approval request, and the owner could still approve it. Now `nook run` prints `Cancelling the run…`, waits up to 3 seconds for that answer, withdraws a pending request, and never starts the command. It exits 130 for SIGINT or 143 for SIGTERM with `The run was cancelled. Nothing was delivered.` This applies to every run, including runs whose secrets are not marked Ask first.

**A clearer message when the secrets that need approval change.** If the owner marks another secret that a waiting run uses as Ask first, `nook run` now says `The secrets that need approval changed while you waited. Run again to ask again.` instead of saying the request expired. The exit code stays 75.
