**When two different signals stop a command, the first one now sets the exit code.** If you press Ctrl+C (SIGINT) and a SIGTERM arrives while the command cleans up, or the other way round, the command exits with the code of the first signal: 130 for SIGINT, 143 for SIGTERM. Before, the last signal set it. Cleanup is, for example, `nook memory download` deleting its partial file, and a second signal does not stop it. This applies to every command except `nook run`, which already used the first signal.
