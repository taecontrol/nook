**When two different signals stop a command, the first one now sets the exit code.** If you press Ctrl+C (SIGINT) and a SIGTERM arrives while the command cleans up, or the other way round, the command exits with the code of the first signal: 130 for SIGINT, 143 for SIGTERM. Before, the last signal set it. Cleanup is, for example, `nook memory download` deleting its partial file, and a second signal does not stop it. This applies to every command except `nook run`, which already used the first signal.

**The mise release of `nook` now includes Node.js 26.13.1.** This Node.js release fixes several high-severity vulnerabilities in TLS and HTTP ([Node.js release notes](https://nodejs.org/en/blog/release/v26.13.1)). The mise release is one executable that carries its own Node.js and uses it to connect to your Nook server over HTTPS. Version 0.7.0 carried Node.js 26.10.0, so update `nook` on every machine where you installed it with mise. The Homebrew formula on macOS runs `nook` on Homebrew's `node`, so `brew upgrade node` keeps it current there.
