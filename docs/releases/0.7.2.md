**`nook vault` lists its subcommands in one order.** Both `nook vault` and `nook vault --help` now list `create` before `import`, matching the usage line that `nook vault` prints and the order in the README. Previously, help listed `import` before `create`. The bash completion script from `nook --completions bash` offers them in the new order too. Commands, arguments, and exit codes stay the same.
